# 🤖 Generative AI for Data Analysis

## 📊 Titanic Survival & Tips Analysis Using Generative AI

This repository contains two data analysis projects completed as part of my **Generative AI for Data, Technology & Finance** learning project.

The projects demonstrate how **Generative AI can be used as an analytical and coding assistant** to generate Python code, structure analysis workflows, create visualizations and support insight-driven interpretation of datasets.

The Python analysis was designed for execution in **Google Colab**, with the code logically divided into cells and supported by comments.

---

## 🎯 Project Overview

The repository contains two independent data analysis projects:

### 🚢 Project 1 — Titanic Survival Analysis

**Business Question:**

> What are the factors that are related to the survival of a person?

The analysis explores relationships between passenger survival and factors such as passenger class, gender, age, fare and family-related attributes.

### 🍽️ Project 2 — Tips Analysis

**Business Question:**

> What are the factors responsible for higher tips?

The analysis explores relationships between tip amounts and factors such as bill amount, gender, smoking status, day, time and party size.

---

## 🧠 Role of Generative AI

Generative AI was used as an analytical and coding assistant throughout the projects.

The main prompt instructed the AI to:

- Act as an expert data analyst specialising in Python and data visualization
- Generate Python code for execution in Google Colab
- Produce logically separated code cells
- Provide well-commented code
- Support data analysis and visualization
- Provide analytical insights based on the results

The purpose was not simply to generate code, but to use Generative AI to support a structured **data → analysis → visualization → insight** workflow.

# 🚢 Project 1 — Titanic Survival Analysis

## Objective

To investigate the factors associated with passenger survival using the Titanic dataset.

### Important Columns Used

The analysis was restricted to the following eight columns:

- `survived`
- `pclass`
- `sex`
- `age`
- `sibsp`
- `parch`
- `fare`
- `alone`

## Analysis Performed

The Titanic project includes:

- Descriptive statistics
- Missing-value analysis
- Outlier analysis
- Univariate analysis
- Bivariate analysis
- Visualization of important variables
- Relationship analysis with the `survived` variable
- Insight-driven interpretation

The bivariate analysis specifically examines the relationship between `survived` and the selected important variables.
